# GEMI Company Analyzer

Εργαλείο που αντλεί στοιχεία εταιρειών από το **ΓΕΜΗ** και παράγει πλήρη αξιολόγηση:
τζίρος, κερδοφορία, ανάπτυξη, ανάλυση ισολογισμού, δείκτες, πιστωτικός κίνδυνος, μέγεθος αγοράς & μερίδιο.

## Τι κάνει

| Ενότητα | Περιεχόμενο |
|---|---|
| Στοιχεία ΓΕΜΗ | Επωνυμία, ΑΦΜ, νομική μορφή, κατάσταση, ΚΑΔ, κεφάλαιο, διοίκηση, δημοσιευμένα έγγραφα |
| Οικονομικά | Αυτόματη λήψη PDF ισολογισμών από ΓΕΜΗ & εξαγωγή κονδυλίων (υποδείγματα ΕΛΠ ν.4308/2014) |
| Ανάπτυξη | Μεταβολή y/y, CAGR πωλήσεων & κερδών |
| Κερδοφορία | Μικτό / EBITDA / EBIT / καθαρό περιθώριο, ROE, ROA |
| Ισολογισμός | Ρευστότητα, μόχλευση, κάλυψη τόκων, Καθαρός δανεισμός/EBITDA, DSO/DIO, σημαντικότερες μεταβολές κονδυλίων |
| Κίνδυνος | Altman Z'' (μη εισηγμένες εταιρείες) |
| Αγορά | Μέγεθος αγοράς (δική σας τιμή → markets.json → Eurostat → άθροισμα ανταγωνιστών), μερίδιο, κατάταξη, HHI |
| Αξιολόγηση | Βαθμολογία 0–100 & διαβάθμιση AAA–CCC σε 5 πυλώνες, δυνατά/αδύνατα σημεία |
| Έξοδος | HTML αναφορά με γραφήματα + JSON για CRM/Excel |

## Εγκατάσταση

```bash
cd gemi_analyzer
pip install -r requirements.txt
```

**API key ΓΕΜΗ** (δωρεάν): εγγραφή στο https://opendata.businessportal.gr → δημιουργία API key.

```bash
export GEMI_API_KEY="το_κλειδί_σας"        # Windows: set GEMI_API_KEY=...
```

## Χρήση

```bash
# Δοκιμή χωρίς API (φανταστική εταιρεία)
python -m gemi_analyzer demo --open

# Αναζήτηση
python -m gemi_analyzer search "ΕΠΩΝΥΜΙΑ"
python -m gemi_analyzer search --afm 099999999

# Πλήρης ανάλυση (αυτόματη λήψη ισολογισμών)
python -m gemi_analyzer analyze 123456789000 --open
python -m gemi_analyzer analyze --afm 099999999 --open

# Με ανταγωνιστές (αυτόματα από ΓΕΜΗ) και γνωστό μέγεθος αγοράς
python -m gemi_analyzer analyze 123456789000 --peer-gemi 111111111000,222222222000 --market-size 250000000
```

### Όταν ο ισολογισμός δεν εξάγεται αυτόματα
Πολλά PDF στο ΓΕΜΗ είναι σκαναρισμένα (εικόνα). Τότε:

```bash
python -m gemi_analyzer fetch 123456789000            # εξάγει ό,τι μπορεί σε financials_<ΓΕΜΗ>.json → ελέγξτε/διορθώστε
python -m gemi_analyzer template                      # ή κενό CSV για χειροκίνητη καταχώρηση
python -m gemi_analyzer analyze 123456789000 --financials financials_123456789000.json --no-fetch
python -m gemi_analyzer analyze 123456789000 --pdf isologismos_2024.pdf:2024
```

Τα στοιχεία από `--financials` υπερισχύουν των αυτόματα εξαγόμενων.

## Μέγεθος αγοράς — πώς υπολογίζεται
1. `--market-size` (δική σας τιμή) — πιο ακριβής για τη **στοχευμένη** αγορά.
2. `data/markets.json` — βάλτε μία φορά εκτιμήσεις ανά ΚΑΔ (ICAP, ΕΕΤΤ, ΕΛΣΤΑΤ, μελέτες) και επαναχρησιμοποιούνται.
3. **Eurostat SBS** — συνολικός τζίρος του κλάδου NACE στην Ελλάδα (αυτόματα, χωρίς key). Είναι ευρύτερος από την πραγματική αγορά-στόχο, άρα το μερίδιο βγαίνει συντηρητικό.
4. Άθροισμα εταιρείας + ανταγωνιστών — κατώτατο όριο, χρήσιμο για κατάταξη.

## Περιορισμοί
- Το ΓΕΜΗ δεν δίνει δομημένα οικονομικά στοιχεία· η εξαγωγή από PDF είναι best-effort — **ελέγχετε πάντα τα νούμερα** (`fetch` → JSON).
- Η βαθμολογία είναι εργαλείο screening, όχι αντικατάσταση due diligence.
- Η δομή του GEMI API έχει αλλάξει ιστορικά· ο client είναι ανεκτικός, αλλά αν αλλάξει το endpoint ορίστε `GEMI_BASE_URL`.
